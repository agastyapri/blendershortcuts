Blender Commands

This page contains a list of useful commands for Blender.

  • Gssssssss: Grab/Move
  • S: Scale
  • R: Rotate
  • E: Extrude
  • Ctrl + Z: Undo
  • Shift + D: Duplicate
  • Tab: Toggle Edit Mode/Object Mode
  • Ctrl + A: Apply Transformations
  • F12: Render Image

For more commands and shortcuts, refer to the official Blender documentation here.
